## Overview

DevTools is a full-stack vanilla application designed to help developers discover popular tools and accessories such as monitors, keyboards, headphones, and mice. In addition to browsing for essential gear, users can share their own setups in the community section, fostering collaboration and inspiration among peers.

## Description

DevTools is a full-stack application crafted for developers to explore and discover essential tools and accessories, including monitors, keyboards, headphones, and mice. Whether you're in search of the best gear or looking to showcase your own setup, DevTools offers a community-driven platform where users can share and exchange ideas, promoting collaboration and creativity in the developer space.


## Features

- Discover Developer Tools: Browse a curated list of popular developer tools and accessories, including monitors, keyboards, headphones, and mice.
- Community Setup Sharing: Share your own developer setup in the community section, and get inspired by other users' configurations.
- User Profiles: Create a profile to personalize your experience and showcase your preferred tools.
- Responsive Design: Optimized for all devices, providing a seamless experience whether on desktop or mobile.

### Installation

1. Clone the repository

```
git clone https://github.com/JairGH/DevTools
```
2. Install the dependencies

 - Install dependencies for server 
```
npm i
```
3. Start the application

From the root directory:
```
npm run start
```
